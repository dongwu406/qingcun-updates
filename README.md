# 轻存更新

安卓与 Windows 的安装包和更新发布。

[下载最新版本](https://github.com/dongwu406/qingcun-updates/releases/latest)

第一次安装带更新功能的版本后，后续在应用右上角点「检查更新」。

- 安卓：下载完成后点「安装更新」，按系统提示确认。支持 Android 10 及以上，覆盖安装保留最近下载记录。
- Windows：首次完整解压 ZIP，双击「轻存.exe」。后续下载完成后点「重启更新」，原来的入口会转到已安装的新版。支持 Windows 10/11 x64。

更新内置 GitHub 原地址与两条备用下载线路，校验发布签名、文件大小和 SHA-256。备用线路不可用时会自动尝试其他地址；不同地区的网络可用性可能变化。

本仓库只用于版本分发，不接收或保存抖音链接、下载记录或用户的视频和图片。

发布流程先上传预发布包，再由 Actions 校验签名和两端文件，通过后自动设为最新版。发布密钥保留在本地，仓库中只有公钥。
